Foundation

Icon system

Library: Lucide, lucide.dev · stroke weight 1.5px, one weight everywhere. The live app already uses lucide-react, so this guide matches the product. In this reference file icons are inline <svg>; in the app, use lucide-react. Every icon uses currentColor.

Size scale
--icon-xs 14
--icon-sm 16
--icon-md 20
--icon-lg 24
--icon-xl 32
Colour via currentColor (icon never changes, the parent's color does)
Decorative vs meaningful
<!-- decorative: text labels it, icon hidden -->
<button><svg aria-hidden="true" focusable="false">…</svg> Download PDF</button>

<!-- meaningful: no text, so the button is labelled -->
<button aria-label="Delete testimonial"><svg aria-hidden="true" focusable="false">…</svg></button>
Forbidden
✕ Icon fonts (<i class="fa-trash">): no currentColor control, extra dependency, a11y noise.
✕ <img src="trash.svg"> for an icon, can't recolour with currentColor, won't follow theme or disabled state.

Tables

Table system

How every admin and public table behaves. The live examples below sit in resizable previews: drag the handle on the right (or use the Phone, Tablet and Full buttons) and watch the readout name the layout in use.

Rules
No sideways scrollingTables respond to the width of their container (CSS container queries, container-type: inline-size), not the window. Below a table's minimum width its rows become cards or stacked rows. Nothing scrolls sideways, on the page or inside the table.
Row heightComfortable by default (16px cell padding); Compact (8px) is optional. Rows stay one height: titles clamp to 2 lines and chips cap with a +n overflow.
ChipsConditions (teal) and products (lime) share one column, capped at 3 chips plus a +n button whose popover lists every value, grouped. Long names truncate with an ellipsis; the full name is in the tooltip and the popover.
ColumnsMerge before you hide, and use a fixed table layout with set widths for select, status and actions so content never widens a column. Author, date, image count and import source sit under the title as one meta line instead of four columns.
ActionsEdit and Publish or Unpublish stay visible; everything else lives in More, with Delete last, in red, after a divider. Icon-only buttons carry an aria-label.
SelectionHeader checkbox (Select all in card layout), selected rows tint, and a sticky bulk bar appears with the actions that apply to many rows.
Paging50 rows per page by default (25 / 50 / 100). Never render every row at once.
OverlaysChip popovers and More menus are never clipped: table containers stay overflow: visible.
SemanticsExplicit role="table", row, columnheader and cell, so screen readers keep the table when cards restyle it.
BreakpointsBy container width. Testimonials: table from 840px, cards below. Images: table from 760px. Import: table from 820px. Text tables: from 600px.

App shell

App shell overview

The frame around every admin page: a navy sidebar, a slim top bar, and content on the page ground. The rules below are the spec; the previews are scaled-down frames at real breakpoint widths.

Behaviour spec
Frame from 960pxFixed 240px navy sidebar and a 56px sticky top bar. Content sits on --bg.
Below 960pxThe sidebar becomes a slide-over drawer from the left; the top bar gains a hamburger.
Below 576pxThe top bar shows the page name instead of the breadcrumb, the Ask AI entry and menu chevron hide, and Private mode shrinks to its lock icon.
Active itemLit on its own route or any child route, so /admin/edit/:id lights up All Testimonials. Marked with aria-current="page".
Dashboard routeThe app lands on /admin/dashboard, so the Dashboard link points there (not /admin); otherwise nothing is lit on the landing page. /admin redirects to it.
Sidebar heightFixed to the viewport height with its own scroll (overflow-y: auto), so no item can fall below the fold on a short laptop screen. With the account actions in the top bar there is no footer to push off.
Pending ReviewCount pill shows submissions waiting for review; hidden at 0.
AccountAvatar menu in the top bar: View public site, How-to guide, Log out. The sidebar has no footer.
LayeringTop bar --z-topbar (300), drawer --z-drawer (400), user menu --z-dropdown inside the top bar, toasts (700) above everything.
DrawerFocus moves into it, Tab stays inside, Escape or the backdrop closes it, focus returns to the hamburger. Choosing a page closes it.
MotionDrawer slides with --duration-slow and --ease-out; nothing moves under reduced motion.
